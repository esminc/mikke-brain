# 手軽さ(A)：みっけん引用投稿

> **方程式における役割:** 意欲(M) × **手軽さ(A)** × きっかけ(P)
> **担う課題:** 他チャンネルで見つけた"いいな"をmikkeへ持ち込む際のハードルを下げる

---

## 1. 設計思想

"いいな"は #its-mikke の外でも日常的に発生している。しかし「他チャンネルの投稿をコピーして貼り直す」手間が小さな壁となり、共有が止まる。

みっけん引用投稿は、メッセージリンクを渡すだけでみっけんが代わりに投稿する仕組みにより、その壁を取り除く。匿名投稿と同様に「関わり方の自由さ」を広げるセーフティネットとして機能する。

---

## 2. 運用仕様

### システムフロー

```
[ユーザー] Slackワークフロー「みっけん引用投稿」で共有したいメッセージのリンクを送信
      ↓
[スプレッドシート] 投稿内容を蓄積（未共有フラグ付き）
      ↓
[みっけん] #its-mikke に投稿
```

### コンポーネント仕様

| コンポーネント | 仕様                                     |
| -------------- | ---------------------------------------- |
| 入力           | Slackワークフロー「[みっけん引用投稿](https://slack.com/shortcuts/Ft09H23G5S0Z/b883ad2e70f26051ec45a3d46cd656d8)」       |
| 自動処理       | GAS：`postQuoteToSlack()` [スプレッドシート](https://docs.google.com/spreadsheets/d/10xp9LNvG2X0RdqeHky7v_SQvDf9Qyrvr89VC-CNdAXQ/edit?gid=1854989080#gid=1854989080)更新をトリガーに自動実行          |
| 語り手         | 公式キャラクター「みっけん」             |
| 投稿先         | #its-mikke                               |
| 利用条件       | 任意（いつでも使用可）                   |
| 対象           | #its-mikke チャンネルの全メンバー        |
