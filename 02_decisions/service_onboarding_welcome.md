# オンボーディング：ウェルカムメッセージ

> **目的:** 新規参加者がmikkeの文脈・使い方を即時に把握し、最初の参加ハードルを下げる

---

## 1. 設計思想

#its-mikke に参加した直後、mikkeの文脈を知らないまま放置されると、タイムラインを眺めるだけで終わりやすい。ウェルカムメッセージは参加の瞬間に自動で届き、「見るだけでOK」「匿名投稿・引用投稿という選択肢がある」ことを伝えることで、オーナーの案内コストをゼロにしながら初動のハードルを下げる。

---

## 2. 運用仕様

### システムフロー

```
[トリガー] メンバーが #its-mikke に参加
      ↓
[Slackワークフロー] ウェルカムメッセージを自動送信
```

### コンポーネント仕様

| コンポーネント | 仕様                                                             |
| -------------- | ---------------------------------------------------------------- |
| トリガー       | #its-mikke へのメンバー参加                                      |
| 自動処理       | Slackワークフローが即時送信                                      |
| メッセージ内容 | Slackワークフロー内で管理（このファイルでは管理しない）          |
| 語り手         | 公式キャラクター「みっけん」                                     |
