# きっかけ(P)：みっけんメッセージ

> **方程式における役割:** 意欲(M) × 手軽さ(A) × **きっかけ(P)**
> **担う課題:** mikkeの存在を定期的に思い出させ、活動の連鎖の「種まき」を行う

---

## 1. 設計思想

基本的には他者の投稿が連鎖することでmikkeは動く。しかし、完全に自由な場は活動が止まることがある。

みっけんメッセージは、mikkeのリズムを優しく作り出す「ペースメーカー」として機能する。公式キャラクター「みっけん」を語り手にすることで、システム通知ではなく親しみやすい仲間からの「問いかけ」として届き、mikkeの雰囲気を保つ。

---

## 2. 運用仕様

### システムフロー

```
[あらかじめ] スプレッドシートにつぶやきメッセージを複数準備しておく
      ↓
[トリガー] 最後の投稿から2週間、投稿がなかったとき
      ↓
[GAS] スプレッドシートを読み込み、未共有のメッセージを1件ピックアップ
      ↓
[みっけん] #its-mikke に投稿
```

### コンポーネント仕様

| コンポーネント | 仕様                                                                 |
| -------------- | -------------------------------------------------------------------- |
| メッセージ管理 | スプレッドシート（つぶやきメッセージを事前準備、未共有フラグで管理） |
| 投稿トリガー   | 最後の投稿から2週間、投稿がなかったとき                              |
| 自動処理       | GAS：スプレッドシートから未共有メッセージを1件ピックアップして投稿   |
| 投稿内容       | mikkeの楽しみ方・FAQを元にしたヒント、参加ハードルを下げる問いかけ   |
| 語り手         | 公式キャラクター「みっけん」                                         |
| 投稿先         | #its-mikke                                                           |

---

## 3. オーナータスク

| タイミング | タスク                                                               |
| ---------- | -------------------------------------------------------------------- |
| 定常       | スプレッドシートのつぶやきメッセージが不足しないよう定期的に補充する |
| 定常       | GASが正常に動作していることを確認する                                |

> メッセージを事前に複数ストックしておくことで、月次の運用負荷はほぼゼロになる。
