# 手軽さ(A)：匿名投稿機能

> **方程式における役割:** 意欲(M) × **手軽さ(A)** × きっかけ(P)
> **担う課題:** 投稿の実行ハードルを極限まで引き下げる

---

## 1. 設計思想

mikkeの主役は「あなたの中のちょっとしたいいな」であり、評価や反応を気にするものではない。しかし、以下の心理的ブレーキが投稿の壁となる。

- 「うまく書けるか不安」
- 「誰かを名指しするのは緊張する」

匿名投稿は、そのブレーキを完全に取り払い、「関わり方の自由さ」というmikkeの価値を保証するセーフティネットである。

---

## 2. 運用仕様

### システムフロー

```
[ユーザー] Slackワークフロー「みっけん匿名投稿」を起動
      ↓
[ユーザー] 匿名投稿メッセージを入力
      ↓
[ユーザー] 投稿タイミングを選択[みっけんにおまかせ（お昼に１件ずつ投稿）]/[即時投稿する]
      ↓
[スプレッドシート] 投稿内容を蓄積（未共有フラグ付き）
[Slackワークフロー] 「みっけん匿名投稿」から Slack DM 送信（キャンセルボタンあり）
      ↓
[GAS] 即時投稿のメッセージを #its-mikke に投稿（選択している場合のみ）
      ↓
[GAS] 営業日の昼ごろに自動チェック（トリガー実行）
      ↓
[みっけん] 未共有の投稿を1件ずつ #its-mikke に投稿
```

### コンポーネント仕様

| コンポーネント | 仕様                                   |
| -------------- | -------------------------------------- |
| 入力           | Slackワークフロー「[みっけん匿名投稿](https://slack.com/shortcuts/Ft09BF2V9T52/b040f31e551f19d44b0a2480e17d223b)」     |
| 蓄積先         | [スプレッドシート](https://docs.google.com/spreadsheets/d/10xp9LNvG2X0RdqeHky7v_SQvDf9Qyrvr89VC-CNdAXQ/edit?gid=1441843392#gid=1441843392)（未共有フラグで管理） |
| 自動処理       | GAS：`postUnsharedMessagesToSlack()` 営業日の昼ごろに定期実行          |
| 出力           | みっけんが #its-mikke に1件ずつ投稿    |
| 利用条件       | 任意（いつでも使用可）                 |
| 対象           | #its-mikke チャンネルの全メンバー      |
| 語り手         | 公式キャラクター「みっけん」           |
| 投稿先         | #its-mikke                             |
