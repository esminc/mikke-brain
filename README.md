# 🧠 mikke-brain

「mikke」の決定事項、思考プロセス、アイデアを中央集権的に管理・運用するための「脳みそ」リポジトリです。
本リポジトリは、人間（チームメンバー）とAI（Claude Code）が共同で読み書きすることを前提に設計されています。

## 📁 ディレクトリ構造

AIのコンテキスト管理（トークン節約と精度維持）のため、情報の状態（ライフサイクル）を5分割しています。

```text
mikke-brain/
├── CLAUDE.md        # 【AI自動制御】ルート直下。AIへのデフォルト指示・基本ルール
├── 01_core/         # 【不変の軸】MVV、ペルソナ、用語集（AIが常に自動参照）
├── 02_decisions/    # 【確定した事実】現在の仕様、ルール、決定事項
├── 03_active/       # 【進行中の議論】生データ、ブレスト草案、現在のスプリント
├── 04_interviews/   # 【インタビュー記録】参加者へのインタビューの生データ
├── 90_meta/         # 【運用ルール】人間向けの管理マニュアルやテンプレート群
└── 99_archive/      # 【過去の遺物】無効になったルール、完了タスク（AIの自律参照から除外）
```

## 📝 各ディレクトリと重要ファイルの定義

- `CLAUDE.md`: Claude Codeが起動時に自動で読み込むシステムプロンプト。「 `01_core` を常に前提とすること」「 `99_archive` は指示がない限り無視すること」などの絶対法則を定義。

- `01_core/`: mikkeの根幹。 `CLAUDE.md` の働きにより、チャット時に手動でコンテキスト指定しなくても常にAIの前提知識として保持される。

- `02_decisions/`: 議論が収束し「決定」した事項のみを配置。AIが事実確認をするための土台。

- `03_active/`: 日々のインタビュー結果やアイデアを配置。最も頻繁に更新される作業領域。

- `04_interviews/`: 参加者インタビューの生データ。参加者の行動・心理の定性データを格納する。

- `90_meta/`: このリポジトリ自体の運用マニュアルや、プロンプトの原本など、メタ的な情報を配置。

- `99_archive/`: 古くなった情報は削除せずここに移動。 `CLAUDE.md` の制御により、人間が明示的に指示しない限りAIはノイズとして無視する。

## ⚖️ 運用ルール (Human-AI Protocol)

この脳みそを陳腐化させず、かつAIのAPIコストを最適化するための絶対ルールです。

### 1. 状態遷移と定着のフロー

mikkeに関する情報は、原則として `03_active` で生まれ、議論を経て以下のいずれかに遷移します（※ `90_meta/` や `CLAUDE.md` などの運用システムファイルは人間が直接管理するため例外とします）。

- **昇格 (Core):** mikkeの根幹に関わる変更は `01_core` を上書きする。
- **昇格 (Decisions):** 新しい仕様や決定事項は `02_decisions` に定着させる。
- **降格 (Archive):** 古くなった情報や不要なアイデアは `99_archive` に移す。

**【MVPショートカットの許容】**
チャット内で即座に「決定事項」として合意が取れたものに限り、無駄なファイル移動を防ぐため、`03_active` を経由せず直接 `01_core` や `02_decisions` に新規作成・上書き定着させることを許可しています。

※ `01_core` や `02_decisions` と、`03_active` に矛盾する情報が長期間混在すると、AIはハルシネーションを起こすため速やかに整理してください。

### 2. デフォルト・コンテキストの自動読み込み

リポジトリ直下の `CLAUDE.md` に、AIへのデフォルト指示（システムプロンプト）が記述されています。
Claude Codeは起動時にこれを自動で読み込むため、毎回「01_coreを読んで」と指示する必要はありません。
そのまま 03_active のタスクについてチャットを開始してください。

### 3. 脳みその更新（手動 or AI自動）

チャットでのブレストが収束し、決定事項が生まれたら、**必ずMarkdownファイルとしてリポジトリに定着させてください。**
更新作業は人間が手動で行っても構いませんが、手間を省くためにClaude Codeに直接ファイルを生成・更新させることを**強く推奨**します。

自動更新の指示例:

```text
今の議論を踏まえて、03_active/new_feature_draft.md を作成して
```

### 4. ファイル命名規則

AIがファイルの中身を推論しやすくするため、ファイル名は `{snake_case_name}.md` に統一し、必要に応じて日付プレフィックスを付与してください。

ファイル名の例:

```text
20260314_user_interview_a.md
```

## 🚀 初期セットアップ

1. リポジトリをローカルにクローンする
2. VS Codeでクローンした `mikke-brain` フォルダを開く
3. Claude Code（またはVS CodeのChat拡張）を起動する

※ AIの振る舞い（アーカイブの除外設定や、コア・コンテキストの読み込み）は `CLAUDE.md` によって自動的に制御されるため、特別な初期設定は不要です。
