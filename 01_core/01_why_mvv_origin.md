## 1. 目指す状態（ゴールの階層）

mikkeのゴールは単一ではなく、以下の2層で定義する。

### 長期理想（mikkeの先にある組織の姿）

**「ちょっとした気持ちや気づきを自然に言葉にできる組織」**

### mikkeが担うゴール（長期理想への土台）

**ポジティブなことを伝え合うことが"ごく普通"の状態になっていること。**

- mikkeはこの「土台」を作ることに責任を持つ
- 土台が定着した先に、長期理想への自然な歩みが生まれる
- mikkeが長期理想そのものを直接達成しようとするのは、スコープ外かつオーバースペック

### なぜポジティブから始めるか

| 観点         | 理由                                                         |
| ------------ | ------------------------------------------------------------ |
| 言語化コスト | ネガティブより言葉にしやすく、参加障壁が低い                 |
| 安全性       | 批判・傷つきのリスクがなく、誰でも発信しやすい               |
| 普及速度     | 「みんなやってる」が可視化されやすく、社会的証明が働きやすい |

## 2. 戦略との接続

mikkeは、このビジョンの**「チームワーク」と「ワクワク」の醸成装置**として機能する。

### 現時点での接続（確定）

### 将来的な可能性（仮説段階・未確定）

> ※以下は確定した方針ではなく、将来の可能性として議論中の仮説である。

- 日々のシェアが「じぶんたちへの投資」になる

## 3. 起源とUniposからの経緯

### Uniposで証明されたこと

- ポジティブなことを伝え合う状態が**前進した実績はある**
- 一部チームで「空気が良い方向に変わった」という声が確認された
- 44期：事業部メンバの約80%が投稿or拍手の経験あり

### Uniposの限界（なぜやめたか）

| 限界の種類   | 具体的な問題                                          |
| ------------ | ----------------------------------------------------- |
| 構造の問題   | 「誰かから誰かへ」送る形式 → 反応への不安が生じやすい |
| ツールの問題 | 専用ツールの使い分けが必要 → 日常動線から外れる       |
| 心理的障壁   | 特別感があり、構えてしまう人が多い                    |

### mikkeが継承・変更すること

- **継承:** ポジティブなことをオープンな場にシェアする行為そのもの
- **変更:** 制約（誰かへ・専用ツール・特別感）を取り除き、「もっと気軽に」する

## 4. 現状のギャップ（なぜ今やるか）

2025年3月「ポジティブフィードバックに関するアンケート」（ITS内）より：

| 指標                                 | 数値  |
| ------------------------------------ | ----- |
| 伝え合うことに価値を感じている人     | 約40% |
| 「問題なく伝えられる」と感じている人 | 約20% |

→ **価値を感じているのに実行できていない人が多数存在する。**
→ 伝えにくさの主因：「チームに習慣がない」「伝える場面がない」「言葉選びが難しい」

このギャップを埋めることがmikkeの直接的な課題である。
