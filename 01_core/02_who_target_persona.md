# WHO / ターゲットと組織状態の定義

> **このファイルの位置づけ:** mikkeが「誰のために」「どんな組織状態を前提に」設計されているかを定義する軸。
> 施策の優先順位・アプローチを変える際はここを参照すること。

---

## 1. 対象チームの分類

### 分類の軸

ITS内のチームを、以下の2軸で整理する。

- **意欲:** ポジティブなことを伝え合いたいという内発的動機があるか
- **共有行動:** 実際にチーム内で伝え合う行動が起きているか

### 四象限

|              | **共有行動あり**         | **共有行動なし**    |
| ------------ | ------------------------ | ------------------- |
| **意欲あり** | タイプA（実行型）        | タイプB（潜在型）   |
| **意欲なし** | タイプC（⚠️ 義務参加型） | タイプD（無関心型） |

### 各タイプの説明

**タイプA（実行型）**
チーム内でポジティブを伝え合う習慣・文化がある。
mikkeへの対応: オープン化を促し、他チームへの社会的証明として機能させる。

**タイプB（潜在型）**
伝えたいが習慣・場面・言葉がない。
mikkeへの対応: 「みんなやってるなら」のトリガーを提供し、動き出しを後押しする。

**タイプC（⚠️ 義務参加型 ― mikkeが作り出してはいけない状態）**
ノルマ感・空気感で投稿しているが内発的動機がないため継続しない。Uniposが44期→45期で参加率80%→50%に落ちた原因として推測される。`04_how_glossary_tone.md` のDON'T「義務感・ノルマ感を出す」はこの象限を生まないための設計指針。

**タイプD（無関心型）**
必要性を感じていない。
mikkeへの対応: 直接変容を狙わない。参加しやすい環境を整えるに留める。

### 優先ターゲット

**タイプA → タイプBへの波及**

- タイプAがオープンに発信することで「みんなやってる」状態を作る
- その可視化がタイプBの伝えにくさを軽減する（社会的証明メカニズム）
- タイプDは強制しない。参加しやすい環境を整えるに留める

## 2. 個人ペルソナ（参加スタンス別）

### チームタイプとペルソナの対応

チームタイプは「組織全体の傾向」、ペルソナは「個人の参加スタンス」を示す。同一人物を異なる粒度で見るものであり、1対1で一致するわけではない。

| チームタイプ             | 対応する個人ペルソナ |
| ------------------------ | -------------------- |
| タイプA（実行型）        | 発信者に近い         |
| タイプB（潜在型）        | 傍観者に近い         |
| タイプC（⚠️ 義務参加型） | 非参加者が多い傾向   |
| タイプD（無関心型）      | 非参加者が多い傾向   |

### ペルソナ1：発信者

- **状態:** 日頃からポジティブなことを伝えたいと思っており、場があれば動く
- **現在の課題:** 発信する場・習慣がない、または特定チーム内でのみ行動している
- **mikkeへの期待:** 発信の場を提供し、行動を引き出す

### ペルソナ2：傍観者

- **状態:** 価値は感じているが、自分から発信することに不安・照れがある
- **現在の課題:** 言葉選びへのハードル、チームに習慣がなく自分だけのような孤立感、伝えるタイミング・場面がつかみにくい
- **mikkeへの期待:** 発信者の投稿が積み重なることで「自分もやっていい」と思えるようになる

### ペルソナ3：非参加者

- **状態:** 価値を感じておらず、参加意欲がない
- **現在の課題:** 参加への動機がそもそもなく、義務感を感じると反発が生じやすい
- **mikkeへの期待:** 「見るだけでもOK」を明示し、強制感を排除する

## 3. mikkeが変容を狙う状態遷移

変容のメカニズムは、組織レイヤーと個人レイヤーの2つの視点で説明できる。両者は同じ現象を異なる粒度で見たものであり、メカニズムの核は共通（社会的証明）である。

### 組織レイヤー（チームタイプ間の波及）

```
[タイプA] ─→ オープンな場で発信 ─→ 「みんなやってる」が可視化 ─→ [タイプB] が動き出す
[タイプD] ──────────────────────────────────────────────────→ (変容を強制しない)
⚠️ 強制・ノルマ感が生じると → [タイプA/B] が [タイプC（義務参加型）] に変質するリスク
```

### 個人レイヤー（ペルソナ間の変容）

```
[非参加者]  ─────────────────────────→  (変容を強制しない)
[傍観者]   ─── 社会的証明の蓄積 ────→  [発信者]
[発信者]   ─── 投稿の積み重ね ───────→  [ポジティブなことが"ごく普通"の状態へ]
```

**注意:** mikkeは「全員を発信者にする」ことを目標としない。
まず発信者を増やし、その可視化が組織の空気をじわじわ変えることを狙う。
